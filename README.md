# Input

The PE03-Todos application is a React Native mobile application developed using Expo. It allows users to enter tasks through a text input field and add them to a to-do list using an Add button. Users can interact with the application to manage their tasks and view them in an organized interface. The application accepts task descriptions as user input.

# Process

The application uses React state to store and manage the task list. When a user enters a task and presses the Add button, the application adds the task to an array and updates the displayed list. Each task maintains a completion status that users can change. The application provides three filter options: All, Completed, and Incomplete. These filters display all tasks, only completed tasks, or only incomplete tasks, respectively. The application also calculates and displays the total number of tasks, completed tasks, and remaining tasks. Task information and updated arrays can be logged to the terminal for verification.

# Output

The application displays a responsive to-do list interface with task input, task statistics, completion controls, and filtering options. It provides immediate visual updates when tasks are added or completed.
